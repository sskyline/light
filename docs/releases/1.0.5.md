# Light 1.0.5

发布日期：2026-09-07。

- 新增 Antigravity 支持：工作状态、每轮计时、工具完成记录、完成/出错及多会话显示。
- 托盘“接入 Hooks...”支持合并 Antigravity 配置。
- 重新接入时，安装器会更新自己生成的旧 Hook 执行路径，支持从开发版迁移到正式安装版；其他 Hook、自定义命令、matcher 和禁用设置保持不变。

Antigravity 暂不检测等待审批、执行中的工具或窗口关闭。默认不注册参与权限决策的 `PreToolUse`，不改动代理或应用启动设置。

## 升级

1. 从托盘退出旧版或开发版 Light。
2. 打开 DMG，把 Light 拖入“应用程序”，替换旧版。
3. 启动安装后的 Light，点击托盘“接入 Hooks...”，迁移已有配置中的执行路径。
4. 在 Antigravity 发起新一轮任务验证。Claude Code / Codex 若提示 Hook 变更，按其界面审核并信任。

macOS 产物为 Apple Silicon（arm64）DMG，未配置 Developer ID 签名或公证。Windows 版本号同步更新，本次未构建 Windows 安装包。
