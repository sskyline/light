# Light 1.1.1

- **会话图钉固定与保留**。悬停或展开会话行时点击右侧图钉可固定会话，固定后常驻暖金色标记并在空闲分组中置顶，免除 1 小时自动回收与 `session_end` 退出清理。已固定会话会持久化保存到本地 `userData/pinned-sessions.json`（取消固定或手动移除即清除），重启 Light 后依然保留；未固定会话维持纯内存不落盘。
- **终端分屏与客户端关闭后恢复拉起（macOS）**。新版 Claude Code / Codex Hook 会随事件补充上报项目工作目录（`cwd`）。点击 `↗` 时优先定位原分屏；若原 Rex、Ghostty、iTerm2 分屏甚至整个终端应用已关闭，且会话带有合法 UUID，Light 会在对应终端原目录自动新建分屏执行 `claude --resume <id>` 或 `codex resume <id>` 恢复对话，并自动记住新分屏标识（包含连点防重、Rex Remote Control 预检与重试防双开、Ghostty 单脚本精确判存）。
- **自定义配置目录与接入健壮性修复**。连接诊断、一键接入、会话标题读取与 Codex 审核关联现统一识别 `CLAUDE_CONFIG_DIR` 与 `CODEX_HOME`（含 `~` 展开）；`.sh` 与 `.mjs` Hook 适配器补齐多级软链解析，且在遗漏 `terminal-source.mjs` 时优雅降级不阻断状态上报；补齐 `hooks/settings.example.json` 全部会话生命周期事件。
- **跨时区进展时间排序修复**。任务进展列表改为按真实毫秒时间戳排序，修正混合 UTC `Z` 与本地时区偏移字符串时的顺序错乱问题。

## 从 1.1.0 或更早版本升级（macOS）

1. 从托盘退出旧版 Light。打开新版 DMG，将 Light 拖入「应用程序」，替换旧版。
2. 启动 Light，在托盘打开「连接与诊断…」，点「接入 Hooks」或「重新接入」，将带 `cwd` 上报与软链容错的新版 Hook 脚本同步到本机（不会重复添加或覆盖你的自定义配置，无需重启 CLI 即可在新事件上生效）。
