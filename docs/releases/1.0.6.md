# Light 1.0.6

发布日期：2026-09-07。

- 新增应用一键切换：展开面板顶部提供 Antigravity、Codex、Claude 三个按钮，一键打开或切换到对应桌面应用。
- 按 macOS bundle ID 经 `open -b` 激活：应用未运行则启动，已运行则置前，已在前台则无操作；点击后面板自动收起，全程不抢焦点。
- Codex 指向 Codex 桌面版（bundle ID `com.openai.codex`，应用显示名为 ChatGPT.app）。目标应用未安装时仅在主进程日志记录，界面无打扰。

## 升级

1. 从托盘退出旧版 Light。
2. 打开 DMG，把 Light 拖入“应用程序”，替换旧版。
3. 启动新版即可，Hook 配置无需变更。

macOS 产物为 Apple Silicon（arm64）DMG，未配置 Developer ID 签名或公证。Windows 版本号同步更新，本次未构建 Windows 安装包。
