# Light 1.0.9

版本日期：2026-11-01。

- 接入 Codex 官方 `Interrupt` Hook。按 Esc 中断正在执行的主会话轮次后，Light 立即回到空闲，清除当前工具和任务计时，保留会话与任务摘要。
- 事件流显示 `cancel` 标签及“用户已取消本轮任务”。下一次真实提问重新开始计时，其他会话保持原有状态。
- 托盘“接入 Hooks…”会补齐新增的 `Interrupt` 配置，超时为 3 秒；保留已有 Hook 和自定义命令。
- 取消应用生成的输入框建议后台请求时，清理过滤标记并继续忽略该请求，避免生成虚假会话。

## 升级

1. 从托盘退出旧版 Light。
2. 打开 DMG，把 Light 拖入“应用程序”，替换旧版。
3. 启动新版，在托盘选择“接入 Hooks…”以更新脚本并补齐 `Interrupt`。
4. 完全重启 Codex，审核并信任新增 Hook；CLI 可通过 `/hooks` 查看。

`Interrupt` 只在主会话的活动轮次被中断时触发，空闲时按 Esc 不触发，子代理不触发。
自定义命令如果指向其他脚本副本，需要更新实际引用的脚本并手动补齐事件配置。

本次已通过 35 项自动化测试及 TypeScript 类型检查，并在本机 Codex 中实测按 Esc 取消、Light 接收事件成功。

macOS 产物为 Apple Silicon（arm64）DMG，沿用现有签名配置，未配置 Developer ID 签名或公证。Windows 版本号同步更新，本次不提供 Windows 安装包。
