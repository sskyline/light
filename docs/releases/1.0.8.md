# Light 1.0.8

版本日期：2026-10-14。

- Codex Hook 过滤应用生成的“下一条消息建议”后台请求，以及同一轮次的工具和结束事件，避免它们显示为用户任务或虚假完成会话。
- 正常用户消息照常转发；在正文中引用后台请求说明不会被过滤。
- 密集工具事件期间，界面状态刷新合并为每 750 毫秒一次，保留事件记录；用户消息、等待审批、完成、错误和手动清理立即刷新。

## 升级

1. 从托盘退出旧版 Light。
2. 打开 DMG，把 Light 拖入“应用程序”，替换旧版。
3. 启动新版，在托盘选择“接入 Hooks…”以刷新用户数据目录里的 Hook 脚本；已有自定义命令保留。
4. 若 Hook 配置发生变化，完全重启对应 Agent，并确认新增 Hook。

自定义命令如果指向其他脚本副本，需要更新它实际引用的脚本。若直接指向本项目的 `hooks/codex-hook.mjs`，更新源码后即可使用过滤逻辑。

macOS 发布产物为 Apple Silicon（arm64）DMG，未配置 Developer ID 签名或公证。Windows 版本号同步更新，本次不提供 Windows 安装包。
