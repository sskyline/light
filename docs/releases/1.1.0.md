# Light 1.1.0

- **会话跳转**。点会话标题可展开或收起进展。macOS 上，会话右侧出现 ↗ 时，点它可回到对应的 Codex、Claude 桌面会话或 Rex、iTerm2、Ghostty 分屏。
- **工具活动**。连续的工具记录合并展示。展开后可查看操作摘要，有文件名或命令摘要时会一并显示。
- **审批提醒**。确认自动审批失败后，胶囊和对应会话会显示未读标记。展开失败记录可查看原因。
- **连接与诊断**。从胶囊或托盘打开诊断面板，可检查本地服务、Hook 配置和最近收到事件的时间，也可以在这里更新 Hook 脚本。

## 从 1.0.9 升级（macOS）

1. 从托盘退出旧版 Light。打开新版 DMG，将 Light 拖入「应用程序」，替换旧版。
2. 启动 Light，在托盘打开「连接与诊断…」，点「接入 Hooks」或「重新接入」。即使提示配置无需修改，这一步也会同步新版脚本和分屏识别所需的 `terminal-source.mjs`。
3. 如果配置有更新，完全退出并重启正在使用的 Claude Code 或 Codex，在 CLI 中用 `/hooks` 确认并信任新增项。Antigravity 会在新一轮对话加载配置。
4. 在原来的应用或分屏里发起一轮任务，在「连接与诊断」里确认对应 Agent 的最近事件时间已更新。

## 已知限制与下一版本计划

- **自定义配置目录兼容**。连接诊断支持读取 `CLAUDE_CONFIG_DIR` 与 `CODEX_HOME`，但应用内「接入 Hooks」仍固定写入默认主目录（`~/.claude/settings.json`、`~/.codex/hooks.json`）。下一版本统一安装与诊断路径。
- **手动安装与软链脚本容错**。`claude-hook`、`codex-hook` 依赖同目录的 `terminal-source.mjs`，且 `.sh` 包装脚本按相对目录解析路径；手动软链到全局路径或漏拷辅助脚本时会报模块缺失。下一版本补充软链真实路径解析与降级兜底。
- **示例配置补全**。`hooks/settings.example.json` 尚未补充 `SessionStart` 与 `SessionEnd` 事件（手动按该示例配置时诊断会显示 `6/8` 部分接入；建议优先使用一键接入或参照 `docs/hooks.md`）。下一版本同步更新示例文件。
- **跨时区时间戳排序**。`TaskProgress` 当前按 ISO 字符串字典序排列事件，内置 Hook（统一 UTC `Z`）不受影响，但外部自定义接入混用带时区偏移（如 `+08:00`）的时间戳时可能出现顺序偏差。下一版本改为按纪元毫秒排序。
- **Subagent 支持**。当前会话按扁平 `sessionId` 聚合，尚未接入 `SubagentStart`、`SubagentStop` 等子代理生命周期事件，也未区分主会话与派生的后台 Subagent；子代理的工具调用会直接混入当前会话进展或表现为普通工具操作。后续版本计划补充父子会话关联及 Subagent 运行状态与进展展示。
