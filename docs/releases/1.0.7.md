# Light 1.0.7

版本日期：2026-09-08。

- macOS 展开面板自动识别 Antigravity、Codex、Claude 桌面应用的安装状态，隐藏未安装应用；全部未安装时隐藏启动按钮区域。
- 已运行应用在按钮文字下方显示圆点，提示文字区分“打开”和“切换到”。点击启动后立即更新状态，面板自动收起。
- 启动时探测应用状态，每轮探测完成后间隔 15 秒再次查询，展开面板时额外刷新；查询失败保留已有状态。
- 优化启动按钮样式：文字调整为 13px、半粗体，运行圆点为 3px，并为按钮显示和隐藏增加动画。
- 非 macOS 保留启动按钮，不启用安装与运行状态探测。

## 升级

1. 从托盘退出旧版 Light。
2. 安装新版并启动，Hook 配置无需变更。

本次同步更新 macOS 与 Windows 使用的版本号，未构建安装包。
